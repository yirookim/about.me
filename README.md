# IRU GREEN PORTFOLIO

1. GitHub에서 `YOUR_USERNAME.github.io` 이름의 Repository를 만드세요.
2. `index.html`과 `style.css`를 업로드하세요.
3. Settings → Pages → Deploy from a branch → `main`을 선택하세요.
4. `https://YOUR_USERNAME.github.io`에서 확인하세요.

수정할 것:
- ○○대학교 → 실제 학교
- ○○은행 → 실제 회사
- YOUR_EMAIL@example.com → 이메일
- YOUR_USERNAME → GitHub 아이디
- LinkedIn 주소
- 경력/자격증/프로젝트 내용

프로필 사진:
`profile.jpg`를 Repository에 추가하고 index.html의 `.photo`를
`<img class="photo" src="profile.jpg" alt="김이루 프로필 사진">`
으로 바꾸면 됩니다.

이력서:
`resume.pdf`를 Repository에 추가하면 DOWNLOAD RESUME 버튼이 연결됩니다.
